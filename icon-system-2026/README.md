# iCreate icon system (Slate family)

**Status: applied** to `icreate-launcher`, `icreate-photo`, and `icreate-web` (2026-11-05).

## Visual language
- Field: cool slate `#1C222A` → `#0B0E12` with soft top-left lift
- Tile: squircle `rx=88` on 512
- Glyph: ivory `#F0ECE6`
- Accent: one structural colour per app
- Family mark: short rounded underline bar

## Layout
- `masters/<id>.svg` — SVG masters
- `png-512/<id>.png` — review renders
- `preview/comparison-sheet.png` — approval grid

Not ArtCraft artwork. Credit for upstream engines belongs in About / Licences, not in icons.
